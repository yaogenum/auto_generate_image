## 覆盖范围

- 家人：拓扑关系、展开聊天、列表、真人离线状态、通话控制展开。
- 世界：上海、东京、名古屋、大阪、香港，覆盖真实 3D、卡通、Moments、家人互动、UI 收起与恢复。
- 记录：Moment 上传/记录入口。
- 分身：数字分身控制台、代答/本人/待确认策略入口。
- 自动动线：家人关系网络 -> 分身代聊 -> 世界地点/Moments -> 记录 Moment -> 分身控制台 -> 回到家人。

## 本轮修复

- 修复截图 QA 误判：重复截图现在按图片 hash 判断，空白/系统启动图不会再因为体积过小阈值低而通过。
- 延长截图等待：默认等待 12 秒，减少冷启动时抓到白屏的概率。
- 增加模拟器素材瘦身：构建后的 `.app/images` 替换为最长边 1200px 的缓存素材，原始素材库保持不变。

## 后续可优化点

- 自动动线前两帧仍会记录到 launch 后短暂空白，属于模拟器冷启动截图时机问题；当前功能可用性不受影响。
- 如果后续要上线真实 App，需要把原图素材改成远程 CDN 或按需下载，而不是直接打入正式包。
